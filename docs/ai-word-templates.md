# AI 生成与 Word 模板

AI 材料生成支持系统模板和教师自己的 DOCX 模板。系统模板是推荐方式；自定义模板属于高级功能。
草稿仍需教师人工确认，确认后才能导出 DOCX 或 PDF。

## 模型调用

官方 DeepSeek V4 默认启用思考模式，而思考内容和最终正文会共同消耗输出额度。材料整理需要的是
可导出的最终正文，因此系统仅在 Base URL 主机为 `api.deepseek.com` 且模型精确为
`deepseek-v4-flash` 或 `deepseek-v4-pro` 时，按官方 OpenAI-compatible 参数发送
`thinking: {"type":"disabled"}`。其他服务商和自定义兼容地址保持原请求协议，不会收到 DeepSeek
专属字段。正式生成仍拒绝空正文，连接测试仍只验证兼容响应结构。

## 输出样式

| 标识 | 页面名称 | 是否上传文件 |
| --- | --- | --- |
| `SYSTEM_GENERAL` | 系统通用模板（推荐） | 否 |
| `TEACHER_ACHIEVEMENT` | 教师成果汇总模板 | 否 |
| `SIMPLE_REPORT` | 简洁报告模板 | 否 |
| `CUSTOM` | 自定义 Word 模板 | 是 |

三个系统模板由项目代码生成，不包含第三方素材。AI 任务会保存创建时选择的模板标识；以后重新导出
历史任务时继续使用该标识，不会因为页面默认值变化而静默换版。自定义模板任务继续保存模板文件引用；
模板被教师删除后，历史任务仍按原有引用规则导出，但模板不会再出现在普通选择列表中。

内置模板支持中文、英文、编号、空行以及 CRLF/LF 多段落正文。系统生成 DOCX 后会重新打开文件，
并按顺序核对所有非空正文行、标题和占位符状态，避免 Word 段落边界造成误判。自定义模板仍执行
独立的严格结构校验。

## 自定义模板流程

精确插入时，在 Word 正文或普通表格单元格中放置且只放置一个：

```text
{{aiContent}}
```

若合法 DOCX 中没有该占位符，上传不会直接失败，也不会静默修改文件。页面会询问是否把 AI 正文位置
添加到文档末尾：

- 选择“返回修改模板”时，不保存文件或数据库记录；
- 选择“添加到文末并上传”时，后端追加一个普通段落占位符，重新验证后才加密保存规范化 DOCX。

页面的“下载示例模板”提供项目自行生成的 DOCX，其中只有一个有效占位符。“下载测试效果”使用固定
示例正文，不调用第三方 AI、不产生模型费用，也不会把测试文件永久保存到服务器。

## 支持与拒绝范围

系统支持普通 DOCX 正文和普通表格单元格中的单一占位符。不支持自动理解任意复杂 Word，也不支持：

- DOC、DOCM、RTF、HTML 或仅修改后缀的文件；
- 加密或需要打开密码的 Word；
- 多个占位符或其他 `{{...}}` 标签；
- 页眉、页脚、文本框、批注、修订、内容控件或复杂域中的动态占位符；
- 宏、ActiveX、外部资源关系或自动访问模板中的外部地址。

模板超过业务附件现有大小上限、文件损坏或结构超过安全限制时会被拒绝。API 返回稳定错误码和安全的
中文提示，不返回服务器路径、XML、模板正文或内部异常。

## 权限和存储

- `/api/ai/**` 只允许 `TEACHER`；`SUPER_ADMIN` 不能借模板接口读取教师私人文件。
- 每位教师只能列出、上传、下载、测试、使用和删除自己的自定义模板，后端不接受前端提供的
  `teacherId` 作为所有权依据。
- 自定义模板沿用业务文件的信封加密存储，持久化目录中是密文；不进入 OCR 附件授权流程。
- 模板结构和所选教师资料会进入本教师的 AI 请求，Word 文件本身不会发送给模型。
- 测试生成通过 HTTP 响应返回，不持久化测试 DOCX。

## 资料来源人员

- 留空表示只使用当前教师自己的资料；本人始终置顶。
- 其他教师只有至少一条当前有效且所有人策略仍开放的 `AI_USE` 资料或附件时才会出现。
- 下拉选项显示剩余可用资料数和 OCR 已确认的可用附件数；选择一名教师不代表可使用其全部资料。
- 每条授权独立对应一份资料或附件。撤销某条授权不会撤销同一教师的其他授权；全部授权失效后，
  该教师会在刷新页面或重新聚焦窗口时从列表和已选项中移除。
- 创建任务时后端会再次逐项鉴权。已撤销、到期、策略关闭或未确认 OCR 的内容不会进入 Prompt。

## 人工检查

1. 选择系统通用模板，填写生成要求并完成一次草稿确认和 Word 导出。
2. 分别下载教师成果汇总和简洁报告模板的测试效果。
3. 下载示例模板并重新上传，确认识别一个正文位置。
4. 上传无占位符 DOCX，先取消，再确认追加，核对取消时未保存、确认后可测试。
5. 上传含两个占位符或未知标签的模板，核对中文错误。
6. 用另一教师和 `SUPER_ADMIN` 访问模板测试接口，核对应安全拒绝。
7. 重新打开历史任务，确认仍按任务创建时的模板样式导出 DOCX/PDF。
