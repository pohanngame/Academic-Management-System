# 教务课表与公共空闲查询

## 功能边界

系统按学期保存教务课表，再在本地查询多名教师的公共空闲。查询和 Excel 导出不再访问教务系统。

- 一次同步读取一个学期的全校教师总表，周次筛选在本系统完成。
- 只保存已经建立姓名映射的教师；未映射教师跳过，不导致本次同步失败。
- 公共空闲表示所选教师在同一学期、同一周、同一天、同一节次组都没有课。
- 调课、占位和实验课在教务单元格中无法区分，全部按占用处理。
- 教务账号和密码只用于当次同步，不写入数据库、日志、备份或 `.env`。
- 系统不定时登录教务，也不把课表写入教学成果或公开主页。

AI 生成页中的“课表占用”尚未接收查询条件，当前不能作为可用功能。

## 使用顺序

### 1. 建立教师映射

使用 `SUPER_ADMIN` 进入“系统管理 → 课表教师映射”。

“课表姓名”必须与教务总表第一列完全一致，不能使用别名。例如总表显示“张挥”，这里也必须填写“张挥”，再选择本系统中的对应教师。同名教师不会自动合并。

保存教师的所属专业和业务角色不会建立课表映射，两项需要分别保存。普通教师不能打开此页面。

### 2. 同步课表

教师和 `SUPER_ADMIN` 都可以打开“课表 → 课表同步”：

1. 填写有权查询教师课表的教务账号、密码和学期，例如 `2026-2027-1`。
2. 只点击一次“开始同步”。教务要求安全验证时，完成页面上的滑块。
3. 等待同步完成。全校总表较大，可能需要一分钟左右。
4. 结果会显示已保存的教师数、课程记录数，以及因未建立映射而跳过的姓名。

同步失败时，密码保留在当前页面，便于修改后重试；同步成功后清除。关闭或刷新页面后需要重新输入。

同一学期再次同步会替换该学期的旧课表。教务网站暂时不可用时，同步会失败，但已经保存的课表仍可查询。

### 3. 查询公共空闲

打开“课表 → 公共空闲查询”：

1. 填写已同步的学期，并选择第 1 至 30 周中的一周。
2. 选择“按专业”或“按教师”。两种范围只能使用一种。
3. 点击“查询”。有课显示占用教师、课程和教室；所有参与教师都没课才显示空闲。

没有课表映射的教师，以及已映射但没有出现在该学期总表中的教师，会列在“未参与判断的教师”中，不参与本次空闲判定。

尚未同步的学期会提示“该学期还没有课表数据，全部时段都不能判定为空闲”，不能把 42 个时段当成全部空闲。

### 4. 导出 Excel

在查询页点击“导出 Excel”。文件包含三张工作表：

- 空闲总览
- 占用明细
- 未参与判断

导出的筛选条件与当前查询相同。未同步学期的文件会说明不能判定为空闲。

## 权限

| 操作 | TEACHER | SUPER_ADMIN |
| --- | --- | --- |
| 课表同步 | 可以 | 可以 |
| 公共空闲查询和 Excel 导出 | 可以 | 可以 |
| 维护课表教师映射 | 不可以 | 可以 |
| 查看教师成果页面 | 可以 | 不可以 |

## 已知边界

- 页面显示节次组 `0102`、`0304`、`0506`、`0708`、`0910`、`1112`，不显示未核实的上课时钟时间。
- 当前采集使用能够查询全校教师课表的账号。该账号是否被学校允许用于系统化采集，需要学校确认。
- 重启 Docker 不会删除已保存课表；只有删除数据卷或替换同一学期的同步结果才会改变数据。
