The complete third-party JSON is deliberately not tracked or bundled because the Gist does not state a redistribution
license. A deployer or `SUPER_ADMIN` must obtain a copy through an authorized channel, verify the year, revision,
SHA-256 and counts above, then upload it through the reference-data administration page.

The system does not download this data and never follows URLs contained in an uploaded JSON document. The JSON format
is defined by `ccf-reference.schema.json`. Replacing the active reference data never changes confirmed paper snapshots.
